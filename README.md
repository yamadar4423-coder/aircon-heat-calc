# 現場エアコン熱量メーター

風量と吸込・吹出の温湿度から、エアコンが実際に処理している熱量（全熱・顕熱・潜熱）を推定する現場用の単一HTMLツールです。スマホでの利用を前提にしています。

**公開URL**: https://yamadar4423-coder.github.io/aircon-heat-calc/

## できること

- **5つの入力から処理熱量を推定** — 風量／吸込 乾球温度・相対湿度／吹出 乾球温度・相対湿度
- **実風量の低下率を任意設定**（40〜110%）— 目詰まりや設置状態で仕様どおり出ていない現場に対応
- **風量はダイキン AX/A シリーズ壁掛形25機種から選択**、または直接入力
- **計算履歴** — 現場名をつけて保存、タップで条件を呼び戻し、全件をTSVでコピー（Excelに貼れます）
- **ホーム画面に追加してオフラインで使用可能**（PWA）
- 全熱／顕熱／潜熱・SHF・除湿量・露点・湿球・定格能力比を表示
- 入力の矛盾（冷房なのに加湿している、温度差が小さすぎる等）を警告

## 計算方法

湿り空気の物性は ASHRAE Handbook Fundamentals の式によります。

```
pws(t)  飽和水蒸気圧（水面上／氷面上）
x  = 0.621945 × pw / (P − pw)              [kg/kg(DA)]
h  = 1.006·t + x·(2501 + 1.86·t)           [kJ/kg(DA)]
v  = 287.042·(t+273.15)·(1+1.6079·x) / P   [m³/kg(DA)]
G  = (風量 × 低下率 ÷ 60) ÷ v              [kg(DA)/s]

全熱 = G × (h₁ − h₂)
顕熱 = G × (1.006 + 1.86·x₁) × (t₁ − t₂)
潜熱 = G × (2501 + 1.86·t₂) × (x₁ − x₂)
```

顕熱と潜熱は、**和が全熱に厳密に一致する**分解式を使っています（一般的な近似式では数%ずれます）。

風量を質量流量に直すときの比容積は既定で**吹出（SA）基準**です。壁掛形はクロスフローファンが熱交換器の下流にあるためで、詳細設定で吸込（RA）基準にも切り替えられます（冷房で3〜5%変わります）。

## 精度についての注意

1. **風量が最大の不確かさ**です。処理熱量は風量にほぼ比例するので、低下率を振って幅を見てください。
2. **冷房時の吹出湿度は誤差が乗ります**。吹出は飽和近く（RH 95%前後）で、湿度計の1%RHの差が潜熱に直結します。全熱より顕熱のほうが信頼できます。
3. **1点測定は代表点になりません**。吹出口は位置で温度がばらつくので、数点の平均を入れてください。

メーカーの性能保証値ではなく、現場での目安を出すためのツールです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（CSS・JS内蔵、外部依存はGoogle Fontsのみ） |
| `manifest.webmanifest` | ホーム画面追加用の設定 |
| `sw.js` | オフライン用サービスワーカー |
| `icon-*.png` / `apple-touch-icon.png` | アイコン |

`index.html` を更新したら、`sw.js` の `VERSION` を上げてください。古いキャッシュが破棄され、更新が端末に届きます。
